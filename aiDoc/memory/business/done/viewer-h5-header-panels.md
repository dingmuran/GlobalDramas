# H5 页头、设置与搜索弹层优化

## H5 轮播手势与平滑移动

### 再次优化过渡连续性

用户反馈仍然生硬。定位到 components CSS 层中的全局 reduced-motion important 规则将此前轮播动画完全关闭；轮播专用规则移入同层提高选择器优先级，普通模式采用 620ms 渐减速曲线，减少动态模式保留 240ms 轻量过渡。拖动改为 requestAnimationFrame 更新轨道 transform，不再每个指针移动重渲染整个页面；释放、取消与失去捕获清理帧请求，短距离拖动恢复目标位置。浏览器确认实际计算过渡从 0s 恢复到 0.24s，双向切换及首尾循环正常，构建通过。

2026-10-10 用户追加：手机轮播支持左右滑动，并优化直接换图的生硬感。轮播改为横向轨道，拖动时实时跟随指针，松手按距离或快速滑动判断下一张/上一张，不足距离回弹。轨道采用 380ms 缓动，首尾使用相邻克隆页完成衔接；隐藏页 inert，避免重复链接进入键盘焦点。移动端 touch-action 保留纵向滚动与缩放；触摸取消恢复位置，拖动期间自动切换暂停，完成后继续。尊重系统减少动态效果设置，直接定位真实页避免依赖 transitionend。

构建通过。浏览器验证左右滑动、短距离保持原页、第一张右滑到第6张、左滑返回第1张。验证浏览器开启减少动态效果，实际动画时间曲线由代码检查；截图 /tmp/gload-reference-proof/mobile-carousel-smooth.png。

2026-10-10：用户要求 H5 设置和搜索面板缩小，页头增加间距，搜索与用户图标不拥挤，搜索激活无背景；最终搜索弹层紧贴搜索图标下方，不垂直居中。

- 手机页头独立于海报，增加顶部安全区与导航间距；菜单、品牌、搜索和用户区域调整列宽，搜索与用户按钮间距 8px。
- 设置弹层宽度最多 280px，内边距 16px，三行统一 42px 高，主题与语言有明确标签。
- 搜索弹层宽度最多 340px，内边距 16px，最大高度 520px/65dvh，结果列表内部滚动；海报 52×72px，标题 13px，最多两行。
