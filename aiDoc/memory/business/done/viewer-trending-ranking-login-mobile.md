# 首页热播榜单与 H5 登录弹窗优化

- 提出日期：2026-10-10
- 当前状态：done

## 用户意图与实现

- 在最新发布之后、精选推荐之前加入热播榜单。
- 使用用户提供的 1–9 数字素材，首位金色、第二位银色、第三位铜色，其余金棕色；数字覆盖海报左下方。
- 桌面复用左右翻页、悬停收藏/播放/分享；H5 使用原生横向滑动。
- 榜单暂使用固定演示顺序，不生成虚假播放量；未来可接真实排序接口。
- H5 登录品牌图高度控制在 120–176px，按钮 48px，缩小标题与留白，保留关闭、登录状态提示与协议链接。

## 验证

- TypeScript 与 Vite 生产构建通过。
- 桌面榜单、390×844 H5 登录弹窗可视检查通过。
- 发布沿用 HTTP、Nginx 与无 hash 路由。
