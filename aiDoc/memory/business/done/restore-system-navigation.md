# 恢复系统管理与分组导航

- 日期：2026-10-09
- 用户反馈：系统管理功能被过度清理，业务成为一级菜单，官方演示菜单无用。
- 范围：恢复角色、菜单、API、用户、字典、参数、Token、版本、操作/登录/错误日志；分组业务；仅删除无用演示与旧生成器；保留官方Pro风格、Go鉴权和数据。
- 状态：完成，本次未提交或推送 Git。
- 实现：恢复系统管理 12 个实际入口；业务按内容、策略与会员、用户与运营、财务、数据、治理分组。导航读取 Go 的授权菜单树，移除无关官方演示路由并关闭 Mock，保留官方视觉。
- 数据安全：弃用全菜单白名单清理，只退休明确生成器和空旧目录；保留自定义菜单、标题、排序与分组，不删除账号或业务数据。修改前备份为 `/tmp/gload-before-system-menu-restoration.dump`。
- 菜单可靠性：拒绝不存在的上级和循环引用；新增目录首个子菜单不清除目录权限，移动菜单补齐新祖先访问；菜单编辑保留参数及按钮配置。
- 验证：Biome、TypeScript、10 项前端测试、生产构建、Go 全量测试、PostgreSQL 业务/迁移/权限集成测试通过。浏览器已登录核对所有系统入口及菜单编辑表单；API 显示真实 149 条，账号显示现有管理员；日志、字典等按真实存量显示，不填充示例数据。新增、授权、导入和删除未在真实浏览器数据上进行破坏性验证。
