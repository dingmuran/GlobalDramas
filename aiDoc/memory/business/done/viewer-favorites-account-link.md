# 收藏与个人中心片单联动

- 日期：2026-10-10。
- 用户要求：点击收藏后，应在个人中心看到收藏的剧集。
- 个人中心默认打开“我的片单”；钱包和观看记录保留独立路由，切换后刷新仍保持当前栏目。
- 收藏成功提示“已加入我的片单”，提供“查看片单”直达入口；取消收藏同步更新列表。
- 片单展示收藏数量，按最近收藏排序，并提供专用空状态与找剧入口。
- 收藏沿用本机持久存储，并监听同一来源标签页的存储变化。当前不包含跨设备账户云同步。
- 验证：浏览器从首页收藏 Rahasia Kota Senja，进入个人中心显示1部剧集；刷新后仍保留；观看记录与片单切换正常。Docker内 TypeScript 与 Vite 生产构建通过。
