# 详情自动播放与竖向切集

- 日期：2026-10-10。
- 用户要求按参考图重构详情页：进入详情自动播放第一集，H5纵向滑动切下一集，删除“你也可能喜欢”；后续要求添加喜欢图标、当前集动态标识和首页品牌顶部。
- 详情和观看路由共用播放器：桌面竖屏播放区域、故事简介、题材、喜欢/收藏/分享与选集网格；保留首页品牌、导航和用户操作，底部不展示在播放页。
- H5使用浏览器原生纵向滚动与scroll-snap，每集占满顶部以下的可用高度；向下滚动下一集，向上返回上一集，选集抽屉可直接跳转。仅当前集挂载视频，其他集显示封面，不同时加载多个视频。
- 进入详情始终从第一集起播，观看路由支持进度恢复；静音自动播放，允许用户通过原生控制栏启用声音。播放结束进入下一集，首尾边界受限，第三集起继续现有解锁流程。
- 新增独立喜欢状态，本机持久保存，兼容旧存储数据；收藏沿用个人中心片单数据。分享复制详情链接。
- 当前集选集按钮显示三条柔和声波；播放时动画、暂停时静止，遵循减少动态效果设置，不制造互动数量。
- H5选集抽屉支持Escape关闭与键盘焦点循环。
- 当前媒资仍为共用Sintel授权样片，并非每集正片；真实剧集播放需提供各集媒资地址或接入平台播放器。
- 验证：详情第1集静音自动播放且时间从0开始；H5滑至第2集继续播放、滑至第3集显示解锁、上滑回第2集；选集抽屉跳回第1集；喜欢刷新保留；原生暂停后动态标识停止。TypeScript与Vite构建通过。
