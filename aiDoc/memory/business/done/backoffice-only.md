# 后台仅保留运营与版权方角色

- 日期：2026-10-08
- 状态：已完成
- 需求：观众发现、观看、收藏、钱包与购买等体验由TK小程序H5前台承担，后台只保留超级管理员与版权方/制片方。
- 实现：删除6个观众页面、播放器、收藏与购买入口、角色200注册及旧后台授权；后台登录和业务路由限制300/888，创建账号不接受观众角色。
- 数据边界：保留观众身份、观看/收藏/权益/订单/会员/钱包/反馈等表与服务，管理员继续查询处理；未实现H5前台或独立观众认证，不发布观众HTTP接口。
- 迁移：启动事务清理旧观众菜单、角色关联、数据权限与Casbin，幂等且不删除用户及gd_*数据。
- 验证：覆盖旧权限迁移、旧观众令牌拒绝、两种后台角色访问、观众账号创建/登录拒绝与保留H5业务履约流程。
- 结果：Docker内PostgreSQL集成测试与前端生产构建通过；重启本地后台后角色为300/888，观众菜单和Casbin权限为0，28张业务表与已有账号保留；Vite代理到真实后台的菜单、schema、账号拒绝和移除端点检查通过。
- 权限优化：后台观看历史、收藏、订单和广告尝试为查询与管理流程；通用新增、编辑仅保留给未来H5服务，不允许管理员创建个人观众行为。
