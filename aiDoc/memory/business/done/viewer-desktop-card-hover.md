# 桌面剧集卡片悬停预览

日期：2026-10-10

需求：Web 鼠标移入剧集卡片展示海报、题材、简介以及播放、收藏、分享；继续观看不展示额外操作，仅增加播放与海报动效。后续要求避免突然放大，展开要平滑、高级。

实现：原位展开卡片，桌面精细鼠标设备延迟160ms展示，整卡仅放大2.5%，底部以网格行从0到1缓动展开（420ms，减弱动画设置240ms）。移开140ms后平滑收起。详情保留单行简介和32px操作按钮，额外占用约70px，当前栏目自然增加高度，不遮挡下一模块。首卡向右/向内放大，尾卡向左，滚动行预留16px安全边距并设置scroll-padding防止吸附后裁切。只允许一张卡片展开。取消旧Portal浮层与固定宽度、跨位置动画。触屏/H5不触发详情，继续观看仅海报轻微缩放与中央播放按钮渐显。

动作：播放链接进入现有播放器第一集；收藏切换现有本地片单；分享复制当前剧集详情链接，并显示成功或复制失败提示。没有虚构播放量。键盘焦点可展开，向下箭头进入快捷播放操作，Escape退出。

验证：收藏切换、分享成功提示、播放地址、键盘快捷操作、继续观看无额外按钮及H5不打开浮层均已浏览器检查，TypeScript与Vite构建通过。

2026-10-10：卡片操作区居中排列，统一36px圆形按钮、17–18px图标、12px间距和1.8px线条；播放三角向右微移1px做视觉居中。

2026-10-10 后续优化：用户认为居中的三个圆形图标生硬，改为左侧带文字的紧凑胶囊播放主按钮，右侧32px无外圈收藏/分享按钮，弱化工具栏感并体现主次。
