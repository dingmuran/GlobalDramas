# 玻璃导航、明暗主题与热门搜索

- 日期：2026-10-09。
- 用户提供圆角导航与热门影片截图，要求高级玻璃感、明暗切换，亮色主文字黑色、暗色主文字白色，搜索输入框点击显示热门影片。
- 导航、搜索、语言与主题按钮采用大圆角、透明材质、背景模糊、饱和度、边缘高光与阴影。没有生成海报。
- 使用 Vite 客户端 ThemeProvider（替换会产生脚本警告的 next-themes），显式亮/暗切换，gload-theme 浏览器存储记忆，不读取系统主题。
- 统一页面、卡片、说明、播放器提示、首页遮罩和弹窗的语义主题颜色，海报艺术内容与原生视频保留自身颜色。
- 新增 SearchBox，组合官方 shadcn Popover/Anchor/InputGroup。聚焦打开热门影片，输入筛选结果，点击影片进入详情，Enter 提交，Esc/外部点击关闭；键盘 ArrowDown 可进入推荐列表。
- 热门列表取 Demo 片库前四项并标明演示精选，不伪造真实播放热度。PC 与手机共用组件，H5 两行导航并展开搜索。
- 依赖与构建继续在 Docker，未改后端/数据库/真实支付，未推送 Git。

- 验证：Docker TypeScript/Vite 构建通过；PC/H5 热门推荐、详情跳转、输入筛选、Enter、ArrowDown、Esc 通过；亮色黑字/暗色白字和刷新主题记忆通过，320/390/768 像素无横向溢出。最终新浏览器页面无控制台错误或警告。
