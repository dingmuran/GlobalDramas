## 当前设计
- 居中深色面板，Web VIP 两列、金币四列；H5 VIP 单列、金币/付款方式两列。
- 使用用户 Downloads 中的会员卡与金币素材，复制到 `web/public/media/ui/vip-card.png` / `coin-stack.png`。通过 CSS 裁切移除素材外部黑色留白及底部原有权益文字。
- 用户明确要求：删除“无限观看/1080p”权益栏、勾选图标、激活红边和右侧多余底色。保留卡片原样；付款方式置于套餐上方，点击只选择方式并显示中性细边框；再点击 VIP 或金币卡片直接发起对应付款流程。未选择方式时提示并聚焦付款区域，无可见复选框。
- 中文人民币 ¥，英文美元 $；所有金额、原价、续订价、确认信息及 Google Pay 请求统一按同一汇率计算，美元保留两位小数。
- Frankfurter API 读取最新 USD/CNY ECB 参考汇率；6 秒超时后保留 2026-10-09 的 6.6921 备用汇率。页面标示汇率与日期，仅演示报价，不代表真实结算价格。

## 付款边界
- Google Pay 加载官方 pay.js，PaymentsClient 固定 TEST，example gateway；选择 Google Pay 后点击套餐调用 loadPaymentData，币种与金额和页面一致。
- 不保存支付 token，不提交业务服务器，不扣款、不增加余额、不建立订阅。
- 其他付款方式显示未接入商户的说明。正式支付仍需商户资质、网关、服务器订单及回调。
- 官方付款窗在当前 IAB 验证环境未能观察到，不能宣称实际付款已验证；浏览器/网络失败有提示，长时间未返回有超时反馈。
