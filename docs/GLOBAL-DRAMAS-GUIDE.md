# Gload Dramas 后台操作说明

运行入口：http://localhost:8080/ 。项目、Go编译、前端服务与PostgreSQL均沿用 `compose.local.yaml`；本地无需安装Go。

## 两类后台角色

- 版权方/制片方（300）：工作台、剧集管理、数据分析、收益中心、版权与授权；只管理自己的内容。
- 超级管理员（888）：管理总览、内容审核、用户与机构、平台财务、策略配置、会员管理、订单与售后、广告与补偿、平台数据、审批审计与告警。现有角色权限工具继续可用。

在“用户与机构 → 用户账号”创建正式版权方/制片方或管理员账号，密码至少12字节。创建机构时填写所属制片方账号ID。敏感操作要求两个不同管理员：一个核对真实外部凭据并申请，一个审批；不能用同一个账号自批。

观众发现、观看、收藏与购买由 TK 小程序 H5 前台承担。后台已移除6个观众页面和角色200，旧观众菜单与权限在启动时清理，账号身份及业务数据保留，不会提升为管理员。管理员仍可查询观看历史、收藏、权益、钱包、会员与订单并处理反馈。H5前台、独立观众认证和前台接口尚未接入，保留的服务用于后续复用。

## 内容发布

1. 制片方创建剧集，填写集数、授权开始/截止和版权证明；可在版权与授权登记合同。
2. 在剧集“业务操作”批量创建单集；编辑单集素材地址、币种/价格与实际处理进度。
3. 可保存内容版本，提交审核；管理员填写审核反馈并通过或拒绝。
4. 已通过内容在素材齐全、处理完成且授权有效时发布；可下架后编辑。授权到期自动下架并生成告警。
5. 供H5复用的播放服务会核对发布状态、授权期限、免费策略、会员或单集权益；后台不提供观众播放器。

## 策略与会员

策略可按剧或全局（剧集ID=0）设置免费集数、广告开关、会员覆盖和生效时间；免费集数=-1为全部免费。启用后才参与影响预览和实际权限计算。

会员套餐填写平台商品ID、权益、价格、币种和有效天数，上架配置供H5前台展示。首购/续费服务保留，订阅有效期和来源由履约生成。人工平台查询结果可在同步记录登记。

## 订单、广告与客服

观众订单先为待支付；后台必须核对真实支付结果并提交凭据，经另一位管理员审批后记为已支付并发放权益。此系统不会替你向支付渠道扣款。

退款申请 → 真实渠道处理/核验退款 → 申请审批 → 审批后记退款并撤销相应权益。恢复记录和反馈可关联订单。

广告尝试不代表成功。管理员核对平台完成回执后申请发奖审批；客服补偿同样经过审批。尚无广告SDK，界面不会播放假广告。

## 财务与数据

账单CSV表头必须为：

```csv
externalId,platform,dramaId,period,currency,grossMinor,feeMinor
```

编号按平台去重；重复或任意错误时整批回滚。净收入=总收入-费用，按币种汇总。对账后填写差异说明，创建结算，核对真实到账流水后申请审批；不能超过同币种同账期可结算收入。钱包仅记录内部支付/退款流水，没有充值、提现或实际转账功能。

数据页读取真实播放事件、来源、短剧记录、会员与广告记录、留存和播放质量；业务为空时不生成测试数据。当前留存尚未成熟的日期显示“观察中”。

## 代码与数据库

- 后端：`server/plugin/dramas/`（Router → API → Service → Model）。
- 前端：`webAdmin/src/plugin/dramas/`。
- 28张表、333字段的中文数据字典：`DRAMAS-DATABASE.md`。
- PostgreSQL建表、注释、索引与引用保护：`DRAMAS-SCHEMA.sql`；运行时插件会自动迁移，不必手动导入。
- 接口契约：`aiDoc/frontend-backend/dramas-contract.md`。

可重复验证（Docker内，所有临时业务记录自动回滚）：

```sh
docker compose -f compose.local.yaml exec -T -e GD_INTEGRATION=1 -e GVA_CONFIG=/workspace/server/config.local.yaml server go test ./plugin/dramas/service -run TestPlatformPostgreSQLWorkflow -v
docker compose -f compose.local.yaml exec -T webAdmin npm run build
```

## 上线前的实际接入

Apple/Google支付与订阅、广告SDK及服务端验签、转码任务、私有素材存储和签名URL尚需平台账号、密钥与部署地址。当前实现可运行的内部管理与人工核对流程；测试通过不代表这些外部平台已经接通。
